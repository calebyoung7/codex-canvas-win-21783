## About Codex Canvas

Codex Canvas is a web browser workspace for developing fictional settings and roleplay material in one organized place. It brings character profiles, locations, factions, lore, timelines, and relationship structures together so writers and collaborative groups can shape a world without scattering notes across separate tools.

The workspace also supports continuous story reading, story-point bookmarks, visual page composition, and multiple world projects. Since information is stored in browser-based local storage, it can be used as a lightweight static web app without requiring a separate server for everyday work.

---

## Features

- Build detailed character profiles for cast and roleplay participants.
- Create location pages with expandable trees and parent-child hierarchies.
- Organize factions, lore, and setting information across multiple worlds.
- Record timeline events and follow story development over time.
- Map connections with relationship and story graphs.
- Read continuous roleplay archives and mark important story points.
- Arrange pages with movable, resizable, layered, and text-wrapped elements.
- Search content, save favorites, select themes, and use backup and restore options.
- Edit freeform text and page elements directly in the workspace.
- Keep separate worldbuilding workspaces for different projects.

## Configuration

Codex Canvas stores workspace information in browser-based local storage. Settings and project data are therefore associated with the browser profile and device where the app is used.

Use the available theme, backup, restore, search, and favorites controls to manage the workspace. For important projects, create regular backups before clearing browser data or changing browser profiles.

## FAQ

### Who is Codex Canvas for?

It is intended for worldbuilders, writers, roleplay groups, and anyone planning a setting with interconnected characters, places, events, and stories.

### Does it require an account?

No account requirement is included in the available project information. The app uses browser-based local storage for its workspace data.

### Where are my settings and projects stored?

Workspace information is kept in the browser's local storage on the device and browser profile where Codex Canvas is used.

### How can I move a project to another browser or device?

Use the application's backup and restore options to preserve and transfer workspace data where supported. Keep a separate copy of important backups.

### Can I work on more than one world?

Yes. Codex Canvas supports multiple world workspaces, allowing separate settings and roleplay projects to be maintained independently.

### What should I do if content is missing?

Check that you are using the same browser profile and device where the workspace was created. If you previously made a backup, use the restore option and verify that the correct project is selected.
